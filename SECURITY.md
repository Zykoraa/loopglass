# Security reports

If Loopglass might open the wrong service, stop the wrong process, expose private data,
or allow a local user to interfere with another user's session, use GitHub's
[private vulnerability reporting](https://github.com/Zykoraa/loopglass/security/advisories/new)
for this repository. Include steps to reproduce and the affected version. Please
avoid posting exploit details or private paths in a public issue.

For ordinary bugs and feature requests, use
[Issues](https://github.com/Zykoraa/loopglass/issues).
